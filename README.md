# Fresh Work - 매장 업무 체크 웹앱

GS THE FRESH 매장 업무 흐름을 참고해 만든 **모바일/PC 공용 시간대별 업무 체크 웹앱**입니다.

## 주요 기능

- 서울 시간(Asia/Seoul)을 기준으로 **현재 해야 할 업무 자동 표시**
- 07:55 출근 기준 일정
- 09:10 냉동물류 / 10:30 공산물류 반영
- 업무별 세부 체크리스트
- 업무 완료 버튼 및 오늘 진행률 표시
- 오늘 전체 일정 / 완료·미완료 필터
- 직원 이름 또는 닉네임 저장
- 브라우저 알림(페이지가 열려 있는 동안 업무 시작 시각에 알림)
- PWA 설치 가능 / 오프라인 캐시
- 완료 상태는 각 직원의 브라우저 `localStorage`에 날짜별 저장

## GitHub Pages에 올리는 방법

1. GitHub에서 새 저장소를 만듭니다. 예: `fresh-work`
2. 이 폴더 안의 파일을 저장소 **최상위(root)** 에 업로드합니다.
3. GitHub 저장소에서 `Settings` → `Pages`로 이동합니다.
4. `Build and deployment`에서 `Deploy from a branch`를 선택합니다.
5. Branch를 `main`, 폴더를 `/(root)`로 선택하고 저장합니다.
6. 잠시 후 `https://사용자이름.github.io/fresh-work/` 형태의 주소로 접속할 수 있습니다.

## 중요한 점: 직원끼리 완료 현황을 공유하려면

현재 버전은 **정적 웹사이트**이므로 모든 직원이 같은 URL로 접속할 수 있지만, 완료 체크 데이터는 각 직원의 브라우저에 따로 저장됩니다.

예를 들어 A 직원이 `냉동물류 완료`를 눌러도 B 직원의 휴대폰에는 자동 반영되지 않습니다.

여러 직원이 같은 완료 현황을 실시간 공유하려면 다음 단계에서 Firebase, Supabase 등의 데이터베이스를 연결하면 됩니다.

## 알림 제한

정적 GitHub Pages만 사용하는 현재 버전에서는 브라우저 탭이 열려 있을 때 시작 시각 알림이 동작합니다. 앱/브라우저를 완전히 종료한 상태에서도 푸시 알림을 보내려면 별도의 푸시 서버(Firebase Cloud Messaging 등)가 필요합니다.

## 업무 시간 수정

`app.js` 맨 위의 `SCHEDULE` 배열에서 각 업무의 `time`, `title`, `desc`, `subtasks`를 수정하면 됩니다.
